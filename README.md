# Currículo Web - Jonatan Moreira

Projeto desenvolvido para a atividade de HTML5, CSS3 e JavaScript.

## Arquivos

- `index.html`: estrutura semântica da página.
- `style.css`: estilização, Flexbox, efeitos e responsividade.
- `script.js`: interações e Canvas.
- `media/`: pasta reservada para imagens e outras mídias.

## Funcionalidades JavaScript

1. Botão de saudação.
2. Formulário que coleta o nome e exibe uma mensagem.
3. Contador de visitas usando `localStorage`.
4. Gráfico desenhado com `canvas`.
